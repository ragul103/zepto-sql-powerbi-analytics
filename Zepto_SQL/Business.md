# Olist E-Commerce SQL Analytics — Business Insights

## Project Overview
Analyzed a sample of the Olist Brazilian e-commerce dataset using MySQL Workbench.

## Key Findings
1. **Total product revenue:** R$258,163.49 across delivered orders in the sample.
2. **Average order value:** R$135.23.
3. **Top revenue city:** São Paulo, with R$42,246.08.
4. **Top revenue category:** `relogios_presentes`, generating R$26,548.87.
5. **Late delivery rate:** 7.39% of delivered orders.
6. **Most-used payment method:** Credit card, with 1,519 payment records.
7. **Customer reviews:** 1,144 of 1,932 reviews received five stars.

## Conclusion
SQL analysis revealed differences in product-category performance, city-level revenue, payment preferences, customer spending, and delivery performance.

Note: These findings describe the selected sample and should not be generalized to the entire Olist business.
